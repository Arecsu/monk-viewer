# Native WebGPU rendering contract — v1.1

Status: implementation contract, NOT acceptance evidence. Supervisor approves changes. WebGL remains reference/default until full acceptance; `auto` must not prefer an unaccepted backend.

## Ownership and pipeline

Native modules live under `src/webgpu/`, import `three/webgpu` and `three/tsl` (no GLSL ShaderMaterial/onBeforeCompile compatibility assumption). WebGL source stays intact. Supervisor owns Common.js, WebGpuPipeline.js, backend selection, renderer.js, main.ts, worker, lab, dependencies/config and integration. No worker edits shared node_modules, package.json or lockfile.

Order: TAA beginFrame/jitter → opaque forward encoded MSAA + velocity MRT → decode + explicit depth export → transparent glass → reactive mask → TAA history/output/state MRT → motion blur → bloom → GT7/Reinhard + dithering → optional SMAA → presentation. No quality reductions. Components own targets/materials, setSize uses physical integer dimensions, dispose is idempotent. Textures passed between components are borrowed, never disposed by consumers. Targets persist across frames; reallocate only on size/sample change. Frame pipeline always restores projection and renderer state in finally.

## Formats, coordinates and color

Opaque: `rg11b10ufloat` encoded HDR + `rgba16float` nearest velocity, `depth32float`, actual 4x samples by default. Resolve color using hardware; discard MSAA color only after resolving; retain MSAA depth. No reverse depth. Hardware depth 0 near / 1 far. Depth policy is **sample 0**, explicitly exported to a real single-sample depth32float attachment for glass depth testing; TAA reads that same sample-0 depth, never an undefined implicit resolve. Depth silhouette parity remains an acceptance gate.

Decode/composited HDR, blur and bloom: rg11b10ufloat. TAA histories rgba16float linear filtered, output rg11b10ufloat, state rgba16float nearest. State = (positive view depth or 0 background, lock, motion pixels XY). Reactive = r8unorm. Tone mapping is the only HDR→display boundary; preserve linear scene color before it and sRGB encode exactly once on presentation. Environment is scene-linear HDR, maps retain source color spaces. No hidden persistent WebGL environment decoder.

Native texture storage and screenCoordinate are top-left. **Algorithmic coordinates are WebGL logical bottom-left** for exact porting: Common.logicalUV, logicalPixel, sampleLogical and loadLogical flip Y at the storage boundary only. Velocity remains (current−previous) UV, positive X right, positive Y up; Z = previous view depth/current view depth−1, W=0. TAA reprojection matrices are WebGL NDC (Z −1..1); Common.webglProjection converts the native camera projection without changing near/far. Actual geometry camera uses renderer.coordinateSystem. Never flip motion Y twice.

## Public component interfaces

All are synchronous after renderer/assets initialization, constructors accept `(renderer, options = {})`; `setSize(width,height)`, `reset()` where temporal, `dispose()` required. The supervisor sets size before rendering. Objects expose enabled plus reference-compatible tuning properties; getters may adapt to native uniforms. Return raw Texture objects, not nodes.

* `Geometry.js`: export `WebGpuGeometry`. options `{scene,camera,samples=4,exposure=1.6,encoding='rgb',specularAA,grazingClamp}` (AA/clamp mutable settings objects matching reference). `prepare(model)` converts materials, includes transparent materials but does not encode them; assigns glass to layer 1, opaque to layer 0. `render({projection})` takes **unjittered WebGL projection** and uses scene/camera from options; returns `{color,velocity,depth,target,meshesMoved}`. depth is retained MSAA depth. Per-mesh previous transforms and unjittered camera VP, reset, newly visible/cull-safe motion; no replacement of NodeMaterial graph cache key. `samples`, `exposure`, `encoding` mutable. `finishFrame()` commits previous state if necessary.
* `Transparency.js`: export `WebGpuTransparency`. options `{scene,camera,exposure=1.6,encoding='rgb',reactiveMask=true}`. `render({color,depth,target})` accepts geometry result, explicitly reads depth sample 0; returns `{color,depth,reactiveMask,target}`; depth is single-sample real depth attachment. Preserve original double-side/blend/depth semantics and mask facing formula. Owns targets; never disposes geometry depth.
* `TemporalAA.js`: export `WebGpuTemporalAA`. options match TemporalAAPass + `{scene,camera}`. `trackedObject` mutable. `beginFrame()` saves native projection, returns `{projection}` unjittered WebGL projection, applies reference Halton jitter if enabled. `render({color,depth,velocity,reactiveMask,meshesMoved})` returns `{color,state}`. `endFrame()` restores projection even on failure; `reset()` invalidates history/jitter/bounds. Expose `stateTexture`, `backgroundBounds`, `historyValid` and reference option/debug properties. Disabled path passes color through without temporal filtering/jitter. Match the reference: motion blur receives hasMotion=false while TAA is disabled and must not read stale state. A zero/invalidated state or unused retained texture is acceptable only when all downstream consumers honor this guard. Use velocity iff `velocityBuffer` truthy; rigid reprojection fallback preserved. Static convergence includes independent meshesMoved. Bounds reuse TemporalAABounds; disable safely for background/fog/near plane/unclamped/unsupported inputs. No weakened algorithm.
* `MotionBlur.js`: export `WebGpuMotionBlur`. options match MotionBlurPass. `render({color,state,bounds,hasMotion})` returns `{color}`; state follows TAA convention; bounds Vector4 in logical UV, full screen if unavailable. Expose `backgroundBounds`, `maxBlur`, reference settings. Preserve separable reduction (not tileSize²) and gather, deterministic frame noise and screen-relative reach. Disabled bypass returns input.
* `PostColor.js`: export `WebGpuPostColor`. options `{smaa=false}` plus optional tuning. `render({color,bounds})` returns `{color,target}` display-linear output, **not yet sRGB encoded**; does not present. Expose `bloom`, `gt7ToneMapping`, `reinhardToneMapping`, `smaaPass`, `dithering` with compatible settings/enabled where applicable. Preserve exact reference bloom filters and height scaling, GT7 grade, dithering and optional SMAA. All HDR textures prior to tone mapping retain >1 values. SMAA works in workers. Supervisor presents final result with one sRGB transform.
* `Environment.js`: export `loadWebGpuEnvironment(renderer,url,{signal}={})` async returning `{texture,dispose}`; texture native HDR equirectangular or PMREM suitable for scene.environment; dispose owns decode intermediates and environment/PMREM. Correct gain-map metadata and fallback/error behavior, native only, main/worker compatible. Export `optimizeWebGpuTextures(renderer,model)` or report if unnecessary.

Common helpers are optional; no new runtime dependencies without supervisor approval. Escalate ambiguity or interface changes rather than inventing incompatible contracts.

## Lifecycle/invalidation

Backend-neutral manager API retains init(data) immediate handle, enableRendering/disableRendering, resize, interaction events, loaded/ready and dispose. Asynchronous backend init must finish before assets/native pipeline. Explicit `webgpu` refuses mislabeled fallback; `auto` observable reports selected backend/reason; user can select `webgl`. Initialization must not bind the display canvas to an incompatible context before fallback decision. If native fails after binding, notify owner to replace canvas (including transferred worker canvas), not WebGL reuse on a WebGPU-bound canvas. Device loss pauses frame loop, invalidates histories, emits status/error, requests safe fresh-canvas fallback. Dispose guards async late completions and cancels scheduled frames/listeners.

Reset history and previous motion on resize, DPR/render-scale change, sample changes, camera cuts, backend switch and reinit. Encoding/exposure changes invalidate histories. TAA begin/end projection restoration is exception safe. One scheduled render loop; no competing browser/GPU owners.
